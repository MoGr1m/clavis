# Clavis — сайт студии (тема C · Тёмный salon)

Next.js (App Router), только русский.

## Запуск

```bash
cd ~/Projects/Clavis/web
npm install
npm run dev
```

Откройте http://localhost:3000

## Страницы

- `/` — главная
- `/portfolio` — портфолио
- `/portfolio/[slug]` — кейс (у Rib's и Chaveta — вертикальное видео)
- `/about` — о студии
- `/services` — услуги и цены
- `/contacts` — контакты

Старые ссылки `/a`, `/b`, `/c` редиректят на корень.
